# OpenCiv2's own sound effects

Made for [OpenCiv2](https://github.com/openciv2/openciv2), which uses these in place of the original's where a game folder lacks them, and with HD graphics in preference to them; its build (`make own-assets`) fetches the game-ready files from a pinned commit. MIT licence ([LICENSE-media](../../LICENSE-media)). The sound effects' sources are CC0: [SOURCES.md](SOURCES.md) credits them.

The 78 sound effects, one for each of the original's `Sound\NAME.WAV`, as `name.ogg` (Ogg Vorbis, 22,050 Hz mono, 2 MB in all), each level-matched to the original it stands in for. Every source is CC0 (public domain); `SOURCES.md` credits each one's sources and says how it was made.

What is still to be found or generated: [docs/NEEDED.md](../../docs/NEEDED.md).
