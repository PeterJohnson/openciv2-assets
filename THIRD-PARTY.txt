OpenCiv2 runtime assets: third-party notices
==========================================

This file covers the artwork and font data distributed by openciv2-assets.
Project licensing is in LICENSE. Notices for libraries linked into the game
executable are maintained separately in the openciv2 source repository.

1. Bitmap font caches: DejaVu
----------------------------

data/native/fonts.bin and data/native/fonts_aa.bin in this repository
(data/fonts.bin and data/fonts_aa.bin in release packages) contain rasterized
glyphs and metrics captured through Wine's font APIs. The generating tools are
tools/probe/fontdump.c and tools/probe/fontdump_aa.c in the game repository.
Those tools and src/platform/text.c document these font substitutions:

  Requested game face       Captured font family
  Times New Roman           DejaVu Serif
  Arial, System             DejaVu Sans
  Courier                   DejaVu Sans Mono

The caches store bitmap representations of those fonts, not Microsoft font
files. The historical generation records do not identify the exact DejaVu or
Wine versions or hashes of the original font files. The recorded family names
are therefore the available source attribution, not a reproducible font-version
pin. The current cache files have these SHA-256 hashes:

  fonts.bin: 6c36598b273b937eb53db224a9cfab82381bb46d43c72140682cff8abcb4bfeb
  fonts_aa.bin: fdd8df78d58a0ad29d2f31303ffc0c8699b8924595e188566c803f2b30ae7393

The complete Bitstream Vera and Arev notices for these DejaVu families appear
below. Their text was taken from the official DejaVu 2.37 LICENSE; this identifies
the notice source, not the unrecorded font version used to generate the caches.

  https://dejavu-fonts.github.io/License.html
  https://raw.githubusercontent.com/dejavu-fonts/dejavu-fonts/version_2_37/LICENSE

2. Replacement artwork
----------------------

The selected replacement images and authored graphics are documented in
assets/atlas-hd/PROVENANCE.md (data/ATLAS-PROVENANCE.md in release packages).
Editable art and generation records live alongside the selected runtime art
in assets/atlas-hd. The repository also retains Noto Sans, Noto Serif and
Noto Sans Mono for authoring/review, with unmodified SIL OFL 1.1 notices at
assets/atlas-hd/fonts/{notosans,notoserif,notosansmono}/OFL.txt. Their pinned
sources are recorded in assets/atlas-hd/fonts/provenance.json. These authoring
fonts and their tools are excluded from the runtime release ZIP.

3. Build tools
--------------

The pack builder uses Python and Pillow, with Pillow pinned in requirements.txt.
These tools and their supporting libraries are installed separately; they are
not bundled in the runtime asset ZIP. Their own distributions carry their
software licenses. Wine was used to capture the historical font caches and is
also not bundled in this package. Optional authoring/review scripts use
Node.js and Sharp (tools/atlas-review/package.json), installed separately.
They are not required to build or consume the runtime release.
